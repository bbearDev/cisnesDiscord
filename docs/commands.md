# 명령어 모음

시스네 디스코드 봇 명령어를 한곳에 모은 표입니다. 자세한 동작과 오류 대응은 각 줄 끝의 런북 절을 보세요.

- **운영자** = 서버 관리(`Manage Guild`) 권한이 있는 사람.
- **멤버는 슬래시 명령을 쓰지 않습니다.** 멤버의 진입점은 게이트 채널 인증 패널의 버튼 두 개뿐입니다 (슬래시 `/인증` 은 없습니다).
- 운영자 명령은 운영자에게만 보이고, 서버 설정에서 권한을 바꿔 보이게 해도 봇이 한 번 더 거부합니다.
- 답장은 모두 **본인에게만** 보입니다.
- `<>` 는 꼭 넣는 값, `[]` 는 빼도 되는 값입니다.
- 명령어 등록 목록의 출처는 `src/main.ts` 의 `commands` 맵(슬래시)과 `buttons` 맵(패널 버튼)입니다. 명령어를 더하거나 바꾸면 이 문서도 같이 고쳐 주세요.

---

## 1. 멤버 — 인증 패널 버튼 (누구나)

게이트 채널의 **치지직 팔로워 인증** 패널에 있습니다. 패널이 어느 채널에 있는지는 `/인증채널` 로 정합니다.

| 버튼 | 하는 일 |
|---|---|
| **[치지직 계정 인증]** | 본인 전용 치지직 로그인 링크를 받음 → 로그인·동의 → 팔로워로 확인되면 인증 역할이 붙고 서버 닉네임이 치지직 채널명으로 바뀜 |
| **[내 연동 상태]** | 내 디스코드 계정이 어떤 치지직 계정에 묶여 있는지 보기 |

- 이미 연동된 사람이 다시 누르면 새 링크 대신 안내만 받습니다. 역할이 빠져 있으면 그때 역할을 다시 붙입니다.
- 링크를 받은 뒤 다시 누르면 **같은 링크**를 다시 보여 줍니다.
- 방금 팔로우했다면 반영까지 시간이 걸립니다. 기다리기 어려우면 운영자가 `/팔로우갱신` 을 실행합니다.
- 차단된 사람(`/블랙리스트`)은 안내만 받고 인증할 수 없습니다.

---

## 2. 운영자 명령어

### 인증 패널

| 명령어 | 하는 일 | 런북 |
|---|---|---|
| `/인증채널 <채널:#채널>` | 인증 패널을 놓을 텍스트 채널을 정하고 **바로 게시**. 게시가 실패하면 왜 실패했는지 답함 | §1-2-a · §4-7 |

- 채널을 옮겨도 **옛 패널은 지우지 않습니다.** 옛 패널의 버튼도 계속 동작하니 필요하면 직접 지우세요.

### 연동 조회·해제

| 명령어 | 하는 일 | 런북 |
|---|---|---|
| `/연동상태 [대상:@멤버]` | 그 멤버가 어떤 치지직 계정에 언제 연동됐는지 보기. 대상을 빼면 내 것 | — |
| `/연동해제 <대상:@멤버>` | 연동을 지움. 그 사람은 다시 인증할 수 있음. **역할은 떼지 않음** | — |
| `/팔로우 <대상:@멤버>` | 그 멤버가 치지직 채널을 팔로우한 지 며칠째인지 (오늘 팔로우 = 1일째, 상류 `!팔로우` 와 같은 규칙). 연동이 없으면 조회 불가 | §7-c |

- `/연동상태` 의 날짜는 **연동한 날**, `/팔로우` 의 일수는 **팔로우한 날**부터입니다. 서로 다른 숫자입니다.

### 차단 (`/블랙리스트`)

| 명령어 | 하는 일 | 런북 |
|---|---|---|
| `/블랙리스트 추가 <대상:@멤버> [사유]` | 인증 역할을 바로 떼고 연동을 지우고, 다시 인증하지 못하게 막음. 사유는 100자까지, 목록에 표시 | §7-d |
| `/블랙리스트 해제 <대상:@멤버>` | 차단만 풂. 연동·역할은 되살리지 않으니 그 사람이 패널에서 다시 인증해야 함 | §7-d |
| `/블랙리스트 목록` | 차단된 사람 보기 (최근 순, 최대 20명) | §7-d |

- `/연동해제` 와 다릅니다. `/연동해제` 는 다시 인증할 수 있게 연동만 지우고, `/블랙리스트 추가` 는 역할을 떼고 다시 인증하지 못하게 막습니다.
- 봇 역할이 인증 역할보다 아래에 있으면 역할 떼기가 실패합니다. 차단은 이미 걸린 상태이니 답장대로 역할만 직접 떼세요.

### 상류·유튜브 동기화

| 명령어 | 하는 일 | 런북 |
|---|---|---|
| `/팔로우갱신` | 상류(chzzkbot)가 팔로워 목록을 **지금** 다시 받게 함. 방금 팔로우한 멤버가 바로 인증할 수 있게 하는 용도. 상류가 채널마다 60초 쿨다운을 둠 | §7-e |
| `/구독갱신` | 유튜브 WebSub 구독 갱신을 **지금** 시도. 자동 갱신은 원래 돌고 있고, 이 명령은 다음 자동 시도까지 기다리는 시간만 줄여 줌. 60초 안에 다시 실행할 수 없음 | §7-b |

- 두 명령 모두 답장이 **성공 · 확인 못 함 · 실패** 로 나뉩니다. "확인 못 함" 은 실패가 아닙니다. 연달아 누르지 말고 1~2분 뒤 결과를 확인하세요 (`/팔로우` 의 스냅샷 시각, 또는 다음 `/구독갱신`).
